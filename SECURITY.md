# Security Policy

## Supported Versions

Security updates are provided for the latest release on `main`.

| Version | Supported |
| --- | --- |
| 0.3.x | Yes |
| < 0.3.0 | No |

## Reporting a Vulnerability

Please do not open a public issue for undisclosed vulnerabilities.

Report security issues by email to **carlosfundora@users.noreply.github.com** with:

1. A concise description of the vulnerability and affected component.
2. Reproduction steps or proof-of-concept details.
3. Impact assessment (what can be exploited).
4. Suggested remediation, if known.

You can expect an acknowledgement within 72 hours and follow-up as triage progresses.
