# rs_gfxgraph

Rust crate in the gfxGRAPH workspace. PyO3-based CUDA graph compatibility bridge for AMD ROCm (gfx1030/RDNA2) — provides `BucketRouter` for shape-bucketed graph dispatch, `ConditionalGraphRunner` for branch-conditional graph execution, and warmup/failure state tracking for graph lifecycle management.
