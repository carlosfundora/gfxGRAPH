# gfxGRAPH skill usage

1. Create a skill directory under `skills/`.
2. Copy `skills/templates/SKILL.md.template` to `skills/<skill-name>/SKILL.md`.
3. Fill in the name, description, and workflow steps.
4. Validate the skill with `bash skills/scripts/validate-skill.sh skills/<skill-name>`.
5. Keep the skill focused on one workflow only.
