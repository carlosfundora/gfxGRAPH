# gfxGRAPH skill usage

1. Create a skill directory under `skills/`.
2. Copy `docs/skills-authoring/templates/SKILL.md.template` to `skills/<skill-name>/SKILL.md`.
3. Fill in the name, description, and workflow steps.
4. Validate the skill with `bash docs/skills-authoring/scripts/validate-skill.sh skills/<skill-name>`.
5. Keep the skill focused on one workflow only.
